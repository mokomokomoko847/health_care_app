# 記録入力画面の要件定義

## 1件の記録として保存する項目

1件の記録は以下の項目を持つ。

### 日時

- 必須
- 現在日時を初期値として自動取得する
- ユーザーによる日時変更を可能にする
- 未来日は入力・保存できない
- 端末のローカル日付を基準に、今日以前の日付を選択可能とする
- 日付選択時と保存時の両方で未来日を拒否する
- TODO: 要確認 — 当日の未来時刻も禁止するか

### 血糖値

- 必須
- 整数のみ
- 最小値: 0
- 最大値: 600
- 単位: mg/dL 固定
- 小数は許可しない
- 未入力は許可しない

### 測定タイミング

以下の2択。

- 食前
- 食後

必須項目とする。

### メモ

- 任意入力
- 未入力を許可する
- 最大50文字（Prototype 1の仮仕様）

血糖値が高かった・低かった場合などに、
ユーザーが補足情報を入力する目的で使用する。

### 食事写真

- 1件につき0〜3枚
- 最大3枚
- 任意入力
- 写真が0枚でも記録を保存できる
- カメラで新しく撮影できる
- 端末内の既存写真から選択できる

## 保存と画面の状態

- カレンダー画面の記録入力ボタンから開く
- 入力チェックで不備がある場合はエラーを表示し、保存しない
- 保存先は共通要件に従う
- 保存失敗時は入力内容を保持し、エラーを表示する
