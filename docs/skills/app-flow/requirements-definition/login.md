# ログイン画面の要件定義

- 未ログインでアプリを起動した場合に表示する
- 有効な認証状態を保持している場合は、ログイン画面を経由せずカレンダー画面へ遷移する
- 入力項目は「メールアドレス」と「パスワード」とし、どちらも必須とする
- パスワードは伏せ字で表示する
- ログインボタンで Firebase を利用した認証を行う
- 認証成功後はカレンダー画面を最初に表示する
- 認証失敗時は原因に応じたエラーメッセージを表示し、ログイン画面に留まる
  - 認証情報が正しくない場合の例：「メールアドレスまたはパスワードが正しくありません」
  - 通信に失敗した場合の例：「通信できませんでした。接続を確認して、もう一度お試しください」
- 認証処理中は重複送信を防止する
- 未認証の状態では記録入力・カレンダー・詳細画面へ進めない
- 新規ユーザー登録・ログアウトの対象範囲は共通要件を参照する
