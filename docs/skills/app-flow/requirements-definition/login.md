# ログイン画面の要件定義

- 未ログインでアプリを起動した場合に表示する
- 有効な認証状態を保持しており、メールアドレスの確認が完了している場合は、ログイン画面を経由せずカレンダー画面へ遷移する
- 同じ画面内で「新規登録」と「ログイン」を切り替えられるようにする
- どちらのモードも入力項目は「メールアドレス」と「パスワード」とし、どちらも必須とする
- パスワードは伏せ字で表示する
- ログインモードでは「ログイン」ボタンで Firebase を利用した認証を行う
- 新規登録モードでは「新規登録」ボタンで Firebase にアカウントを作成する
- 新規登録と認証が成功した場合は確認メールを送信し、メールアドレスの確認が完了するまではカレンダー画面へ遷移しない
- 新規登録失敗時は新規登録モードに留まり、原因に応じたエラーメッセージを表示する
  - 例：「登録できませんでした。入力内容を確認してください」
- 認証成功後、メールアドレスの確認が完了している場合はカレンダー画面を最初に表示する
- 認証失敗時は原因に応じたエラーメッセージを表示し、ログイン画面に留まる
  - 認証情報が正しくない場合の例：「メールアドレスまたはパスワードが正しくありません」
  - 通信に失敗した場合の例：「通信できませんでした。接続を確認して、もう一度お試しください」
- 登録・認証処理中は重複送信とモード切り替えを防止する
- 未認証の状態では記録入力・カレンダー・詳細画面へ進めない
- カレンダー画面からログアウトできるようにする。
- ログアウトした場合は Firebase Authentication の認証状態を解除し、ログイン画面へ戻る。
- ログアウト後は、再度ログインするまでカレンダー・記録入力・詳細画面を利用できない。
- ログイン画面に「パスワードを忘れた方」を設ける。
- 登録済みのメールアドレスを使用して、パスワードを再設定できるようにする。
- 「パスワードを忘れた方」を押した場合、パスワード再設定用のメールアドレス入力画面を表示する。
- ユーザーが登録済みのメールアドレスを入力し、「再設定メールを送信」ボタンを押すと、Firebase Authentication を使用してパスワード再設定メールを送信する。
- 再設定メールの送信に成功した場合は、メールを送信したことをユーザーに表示する。
- 再設定メールの送信に失敗した場合は、原因に応じたエラーメッセージを表示し、メールアドレス入力画面に留まる。
- ユーザーは受信した再設定メール内のリンクを開き、新しいパスワードを設定する。
- 新しいパスワードにも、新規登録時と同じ「8文字以上・英字を1文字以上・数字を1文字以上」の条件を適用する。
- パスワード再設定後はログイン画面へ戻り、新しいパスワードでログインする。
- 登録時のパスワードは8文字以上とする。
- パスワードには英字と数字をそれぞれ1文字以上含める。
- 記号は使用可能とするが、必須とはしない。
- 新規登録時に、登録したメールアドレスへ確認メールを送信する。
- ユーザーは受信した確認メール内のリンクを開き、メールアドレスの確認を完了する。
- メールアドレスの確認が完了するまでは、記録入力・カレンダー・詳細画面を利用できない。
- メールアドレスの確認完了後、カレンダー画面へ進めるようにする。
- 確認メール送信後は、メールアドレスの確認待ち画面を表示する。
- 確認待ち画面には「確認が完了しました」ボタンを設ける。
- 「確認が完了しました」を押した場合、Firebase でメールアドレスが確認済みか再確認する。
- メールアドレスが確認済みの場合は、カレンダー画面へ遷移する。
- メールアドレスが未確認の場合は「メールアドレスの確認が完了していません。」と表示し、確認待ち画面に留まる。
- 確認待ち画面には「確認メールを再送する」ボタンを設ける。
- 確認メールの再送に成功した場合は、再送したことをユーザーに表示する。
- 確認メールの再送に失敗した場合はエラーメッセージを表示し、確認待ち画面に留まる。
- ログイン／新規登録のモードを切り替えた場合、入力済みのメールアドレスは保持する。
- パスワードはモード切り替え時にクリアする。
