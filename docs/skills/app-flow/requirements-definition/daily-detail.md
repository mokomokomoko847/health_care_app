# 日付ごとの詳細画面の要件定義

記録がある日付を選択した場合は以下の流れとする。

カレンダー
↓
日付を選択
↓
その日の詳細画面（記録一覧）

例:

8月15日を選択

12:30
血糖値: 120 mg/dL
食前
[食事写真]
メモ: ○○○

19:00
血糖値: 145 mg/dL
食後
[食事写真]
メモ: ○○○

同じ日に複数の記録が存在することを前提とする。

## 表示と操作

- 選択した日付に属する記録を表示する
- 各記録の日時・血糖値・測定タイミング・メモ・食事写真を確認できる
- 戻る操作でカレンダーへ戻る
- 取得結果が0件の場合は空状態を表示する
- 読み込み中と取得失敗を区別して表示する
- 保存済みの記録は後から編集可能とする。
- 血糖値および測定日時については、測定器に保存されている測定値・測定日時を正とし、アプリ側の入力内容はそれと一致することを原則とする。
- 保存済みの血糖値または測定日時を訂正した場合は、訂正前の内容も履歴として保持し、訂正によって過去の入力内容を完全に削除しない。
- 訂正履歴がある記録についても、通常は現在の血糖値・測定日時を表示する。
- 訂正履歴がある記録には「訂正履歴」を確認できる操作を設け、訂正前と訂正後の内容をユーザーが確認できるようにする。
- 「訂正履歴」ボタンは、訂正履歴が存在する記録にのみ表示する。訂正履歴が存在しない記録には表示しない。
- 訂正履歴が存在する記録には、「訂正あり」と表示し、訂正された記録であることをユーザーが識別できるようにする。
- 訂正履歴には、訂正日時・訂正前の血糖値および測定日時・訂正後の血糖値および測定日時を保持する。
- 訂正履歴には、訂正を行ったユーザーの表示名やメールアドレスは表示しない。
- 同じ記録を複数回訂正した場合は、すべての訂正履歴を時系列で保持し、過去の訂正履歴を上書き・削除しない。
- 訂正履歴は、訂正日時の降順（新しい訂正 → 古い訂正）で表示する。
- 訂正履歴には、訂正日時・訂正前の血糖値および測定日時・訂正後の血糖値および測定日時を表示する。
- 訂正履歴は、その対象となる記録が存在する限り保持する。
- 訂正履歴画面から戻る操作をした場合、その訂正履歴を開いた元の記録がある日付ごとの詳細画面へ戻る。
- 一度保存された訂正履歴は、後から編集・削除できない。
- 訂正履歴画面は閲覧専用とし、訂正履歴画面から記録内容の編集・削除はできない。
- 血糖値または測定日時を変更して保存する場合は、保存前に「血糖値または測定日時が変更されています。この内容で訂正しますか？」と確認を表示する。
- 「訂正する」を選択した場合のみ保存し、「キャンセル」を選択した場合は編集画面に留まり、入力内容を保持する。
- 訂正履歴は、血糖値または測定日時を変更した編集内容の保存に成功した時点で作成する。編集をキャンセルした場合や保存に失敗した場合は作成しない。
- 保存前と保存後の血糖値および測定日時を比較し、どちらにも変更がない場合は訂正履歴を作成しない。
- 血糖値または測定日時を過去と同じ値へ戻した場合も、新たな訂正として扱い、既存の訂正履歴は削除せず新しい訂正履歴を追加する。
- 血糖値または測定日時を訂正する際、訂正理由の入力は求めない。
- メモの変更は訂正履歴の対象とせず、最新の内容のみを保持する。
- 測定タイミングの変更は訂正履歴の対象とせず、最新の内容のみを保持する。
- 保存済み記録に添付された写真は、後から変更・削除可能とする。
- 食事写真の変更・削除は訂正履歴の対象とせず、最新の状態のみを保持する。
- 記録は測定日時の昇順（古い時刻 → 新しい時刻）で表示する。
- 保存済みの記録を編集する場合は、記録入力画面を編集モードとして再利用する。
- 各記録に「編集」ボタンを設け、押した場合はその記録の内容を記録入力画面に引き継ぎ、編集モードで表示する。
- 編集内容の保存に成功した場合、測定日時の日付に変更がなければ元の日付の詳細画面へ戻り、更新後の内容を表示する。
- 測定日時の日付を変更して保存した場合は、変更後の測定日時の日付の詳細画面へ移動し、更新後の記録を表示する。
- 編集内容の保存に失敗した場合は、入力内容を保持したまま編集画面に留まり、エラーメッセージを表示する。再度保存を実行できるようにする。
- 編集途中でアプリが終了した場合、未保存の変更内容は保存しない。次回表示時は、最後に正常保存された内容を表示する。
- 編集内容を変更した状態で保存せずに戻る操作をした場合は、「編集内容が保存されていません。戻りますか？」と確認を表示する。
- 戻ることを選択した場合は変更内容を破棄して元の日付の詳細画面へ戻り、キャンセルした場合は編集画面に留まる。
- 編集モードでは、測定日時・血糖値・測定タイミング・メモ・食事写真を変更可能とする。ただし、記録そのものを削除することはできない。
- 編集モードでも、測定日時を現在日時より未来の日時へ変更することはできない。
- 日時の変更時には「※現在より未来の日時は選択できません。」と案内を表示し、未来日時が保存処理まで到達した場合は「未来の日時では保存できません。日時を確認してください。」とエラーを表示する。
- 「記録を追加」を押した場合、選択中の日付を初期値として記録入力画面を開く。
- 過去の日付から記録入力画面を開いた場合、日付は選択中の日付、時刻は画面を開いた時点の現在時刻を初期値とする。
- 今日の日付から「記録を追加」を押した場合、日付は今日、時刻は記録入力画面を開いた時点の現在時刻を初期値とする。
- 選択した過去の日付に記録が0件の場合も、「この日の記録はありません」と表示したうえで「記録を追加」ボタンを表示する。
- 今日および過去の日付の詳細画面には「記録を追加」ボタンを設ける。
