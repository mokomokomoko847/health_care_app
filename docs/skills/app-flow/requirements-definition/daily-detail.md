# 日付ごとの詳細画面の要件定義

記録がある日付を選択した場合は以下の流れとする。

カレンダー
↓
日付を選択
↓
その日の詳細画面（記録一覧）

例:

8月15日を選択

12:30
血糖値: 120 mg/dL
食前
[食事写真]
メモ: ○○○

19:00
血糖値: 145 mg/dL
食後
[食事写真]
メモ: ○○○

同じ日に複数の記録が存在することを前提とする。

## 表示と操作

- 選択した日付に属する記録を表示する
- 各記録の日時・血糖値・測定タイミング・メモ・食事写真を確認できる
- 戻る操作でカレンダーへ戻る
- 取得結果が0件の場合は空状態を表示する
- 読み込み中と取得失敗を区別して表示する
