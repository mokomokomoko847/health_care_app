# カレンダー画面の要件定義

- ログイン成功後の最初の画面とする
- 日付ごとに記録を見返すためのカレンダーを表示する
- 記録入力画面へ遷移するボタンを配置する
- 記録がある日付をタップすると、その日の詳細画面へ遷移する
- 同じ日付に複数の記録がある場合も、その日付の詳細画面で確認できる
- 記録入力画面から戻った際は、保存された記録を反映する
- 読み込み中と取得失敗を区別して表示する
- - 未来の日付はカレンダー上に表示するが、タップによる選択は不可とし、詳細画面へは遷移しない。
- 記録がない過去の日付もタップ可能とする。
- タップした場合は日別詳細画面へ遷移し、「この日の記録はありません」と表示する。
- 記録が1件以上ある日付は、日付部分の背景を青色で表示する。
- 記録がない日付は、日付部分の背景を白色で表示する。
