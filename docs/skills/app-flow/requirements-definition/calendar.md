# カレンダー画面の要件定義

- 認証済みかつメールアドレス確認済みのユーザーに表示する最初の画面とする
- 日付ごとに記録を見返すためのカレンダーを表示する
- 記録入力画面へ遷移するボタンを配置する
- 記録がある日付をタップすると、その日の詳細画面へ遷移する
- 同じ日付に複数の記録がある場合も、その日付の詳細画面で確認できる
- 記録の追加・編集・削除後に戻った際は、最新の記録状態を反映する。日時の訂正で日付が変わった場合は変更前後の両日を更新する。
- 読み込み中と取得失敗を区別して表示する
- 未来の日付はカレンダー上に表示するが、タップによる選択は不可とし、詳細画面へは遷移しない。
- 記録がない今日・過去の日付もタップ可能とする。
- タップした場合は日別詳細画面へ遷移し、「この日の記録はありません」と表示する。
- 記録が1件以上ある日付は、日付部分の背景を青色で表示する。
- 記録がない日付は、日付部分の背景を白色で表示する。
- ログアウトボタンを設ける。認証解除・ログイン画面への遷移・ログアウト後の利用制限は login.md に従う。
