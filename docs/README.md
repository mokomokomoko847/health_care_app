# Docs Overview

## プロジェクト名

楽ちん報告アプリ（仮）

## この docs の読み方

この docs は、楽ちん報告アプリ（仮）の要件と開発ルールを整理したものです。

- アプリの目的、機能要件、Prototype 1 の範囲を確認したい場合は `product-requirements.md` を読む
- Codex の作業ルール、Human への確認事項、学習方針を確認したい場合は `development-rules.md` を読む

## ドキュメント一覧

- `product-requirements.md`
  - アプリの目的
  - 開発技術
  - 1件の記録として保存する項目
  - 履歴表示
  - Prototype 1で実装しないもの
  - Prototype 1の完成条件

- `development-rules.md`
  - Codexの作業ルール
  - Humanへ確認する事項
  - Codexに任せてよい事項
  - Flutter学習のためのルール
  - タスク完了時の報告

## 最初に読むファイル

1. アプリの仕様を把握したい場合は `product-requirements.md`
2. 作業の進め方を把握したい場合は `development-rules.md`
